# 텍스트 분석 포화 판정 (2026-10-11)

텍스트(온라인 글) 단계에서 할 분석을 어디서 멈출지 정한 문서다. 결론: **텍스트로 답할 수 있는 질문은 답했고, 남은 불확실성은 설문·사람 검수로만 줄어든다.** 이후 텍스트 분석은 아래 '하지 않기로 한 것'의 이유로 의미가 작다.

## 1. 포화 기준

보고서의 핵심 주장마다 셋이 있으면 포화로 본다.

1. 신뢰도를 숫자로 쟀다.
2. 견고성(다른 표본·방법·규칙)으로 다시 확인했다.
3. 남은 불확실성은 텍스트로는 답할 수 없는 것(시장 비중, 인구 구성, 가격 수용, 인과)뿐이다.

| 주장 | 근거 | 신뢰도 | 견고성 | 남은 불확실성 → 다음 단계 |
|---|---|---|---|---|
| 니즈·순간 세그먼트 6개 | LCA k=6 (06, 06_1) | 부트스트랩 Jaccard 0.66~0.92 | 시간 창 ARI 0.91, KMeans ARI 0.43, 카페만 재군집 코사인 ≥0.96, 카페 외 4/6 재현(R) | 사제 보충파·공간 활용족은 카페 전용 → **설문 LCA로 존재 확인** |

## 3. 하지 않기로 한 것 (수익 체감)

| 후보 | 하지 않는 이유 |
|---|---|
| 코드북 v3 재라벨(보험 할인, 블루링크 유료 전환) | 해당 토픽 글이 유효 글의 3~4%라 세그먼트 구조를 바꾸지 못함. 설문 문항으로 직접 묻는 편이 낫다 |
| BERTopic(문장 임베딩) 재분석 | NMF 대비 해상도만 오름. 코드북 공백 후보는 이미 확인(E8) |
| 세그먼트 시계열 추이 | 수집이 최신순 검색이라 시점별 글 수가 편향 — 추세 해석 불가(E7에서 비율만 사용) |
| 연령·성별 추정 강화 | 단서 보유율 2~28%로 판단 불가가 대부분. 텍스트로는 개선 한계 |
| 더 큰 모델로 재라벨 | 정답 v2 기준 개선 폭보다 정답 자체의 불확실성(1인 판정)이 큼 — 사람 검수가 먼저 |
| 추가 수집 | 시드 포화 확인됨. 네이버 데이터는 10-30 삭제 예정 |
