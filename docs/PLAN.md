### 0.2 롯데마트에서 그대로 가져올 것
1. **2단 구조:** 페르소나 → 페르소나 안의 #해시태그 니즈 세그먼트(%, 건수, 인용). 롯데마트 기준으로 페르소나 5개에 니즈 조합 20개였다.
2. **두 트랙 구조:** 니즈 트랙과 데모 트랙을 따로 진행하고 마지막에 합친다.
3. **아래→위 코드북:** 반복 패턴을 자연어로 그룹핑해서 코드를 만든다.
4. **인사이트 장 형식:** "헤드라인 + 근거 한 줄"로 쓴다.
5. **카드 앞면 레이아웃과 해시태그 이름 짓기:** "#상황+정체성" 형식으로 짓는다(예: #방학세끼지옥맘 → #좁은칸승하차아빠).
6. **생애 전환점 인사이트:** 예: "이유식 → 유아식 전환기가 요리 입문의 트리거", "30대(영유아)에서 40대(초등)로 전환 중". 우리 쪽에서는 첫차 → 결혼 → 출산 → 학령기 → 교체·은퇴의 전환점마다 생기는 FoD 순간을 본다(5.10).
7. **아이디어 카드와 니즈의 연결:** 아이디어 카드마다 어떤 #해시태그 니즈에서 나왔는지 표기한다.

3.2 오픈 코딩 절차:
1. 소스·코드별 층화 표본 2,000건을 뽑는다.
2. LLM이 결과 문장을 쓴다. 형식은 "방향 + 지표 + 대상"이고 해법·기능명은 금지한다.
   - 예: "좁은 칸에서 아이를 태우고 내릴 때 문을 다 여는 데 드는 시간을 줄인다"
3. 결과 문장을 임베딩 군집으로 묶고, 군집마다 LLM이 이름을 붙이고 사람이 검토한다.
4. **포화 곡선**: 표본을 500 → 1,000 → 2,000으로 늘려도 새 군집이 나오지 않는지 확인한다.

## Step 4. 라벨링 🔄

### 4.1 정답 세트
- 지금 300건(v1)에 B층·생애단계·신규 상황 150건을 더해 v3 450건으로 만든다. 코드마다 양성이 최소 15건이 되도록 층화한다.
- 팀 2인이 **100건 이상**을 겹쳐 라벨한다. Cohen κ와 Krippendorff α를 보고한다.
- 코드별로 LLM 대 사람 κ를 낸다. 기준점은 Co-persona(κ .76, 정확도 약 81%)이다.

### 4.2 라벨 항목

| 구분 | 항목 |
|---|---|
| 코드 | layer, situation, journey(A층), attitude(A층), life_stage, gender |
| 패싯 | `outcome_statement`(결과 문장, 해법 금지), `intensity` 1~3, `frequency`, `wtp_signal`, `substitute`, `sentiment`, `actor`(본인·배우자·자녀·부모) |
| 근거 | 코드·패싯마다 원문 부분 문자열 인용. 검증에 실패하면 삭제 |

### 4.3 실행
1. 정보성·저신호 차단
2. Haiku 5.5 medium 배치(전체)
3. Opus 5.5 low 배치(A_FOD, low confidence, F1 하위 코드)
4. 근거 검증, unknown 원인 감사

예산은 약 85달러다(DESIGN.md 4.3).

| 5.10 | **생애 전환점** | 전환 표현("둘째 생기면", "결혼 후", "은퇴 후", "아버지 차 물려받아") × 상황·FoD 니즈. 전환 직전·직후 니즈 차이 | `transitions` |
| 5.11 | 작성자 단위 | 작성자 ID가 있는 소스에서 작성자별 코드 집계 → 글 단위 세그먼트와 비교 | `author_level` |

### 5.12 텍스트 기회 신호 지수
- 계산: 유병률 × 평균 강도 × 부정 비율 × 대체재 가중
- 이름은 ODI가 아니다. **순위 비교에만** 쓴다.
- 설문 ODI 점수(8.2)와의 순위 상관을 검증 지표로 둔다.

## Step 6. 세그먼트 → 페르소나 ⏳

### 6.1 이름 규칙
- 텍스트 결과: "니즈·순간 세그먼트" (예: M1 좁은 칸 승하차)
- 설문으로 확인되면 "페르소나"로 부르고, 사람 이름과 #해시태그를 붙인다.

### 6.2 승격 기준

| 기준 | 조건 | 필수 여부 |
|---|---|---|
| 안정성 | 세그먼트별 부트스트랩 Jaccard ≥ .75 | **필수** |
| 규모 | ≥ 5%이고 ≥ 200건 | 3개 중 2개 |
| 출처 | 단일 출처 ≤ 70%, 출처를 하나씩 빼도 유지 | 3개 중 2개 |
| 차별성 | 상위 FoD 기회 또는 장벽이 다른 세그먼트와 다름 | 3개 중 2개 |
| 식별 가능성 | 설문 골든 질문으로 재현(홀드아웃 ≥ 70%) | 설문 후 필수 |

미달 군집은 "하위 주제·후보"로 보존한다.

### 6.3 합치기 순서
1. 니즈 세그먼트(5.3)
2. #해시태그 니즈(5.4)
3. 교차 언급(5.5)
4. 저니 장벽(5.6)
5. 데모 오버레이(5.8)
6. 전환점(5.10)
7. 사람이 이름 확정
8. LLM 서술

### 6.4 서술 근거 규칙
- 카드 문장마다 코드 ID와 인용 ID를 연결한다. 근거 없는 문장은 자동으로 삭제한다.
- 고정관념은 사람이 점검한다. 성별·연령 표현은 데이터 근거가 있을 때만 쓴다.

## Step 7. 결과물 ⏳

### 7.1 페르소나 카드: 앞면 (롯데마트 p13 형식)

| 영역 | 내용 |
|---|---|
| 머리 | 이름 · 한 줄 프로필 · 분석 건수 · 텍스트 비중(설문 비중 나란히) |
| INSIGHT | 2줄 |
| 누구 | 생애단계·성별·차종·EV 상위 2개씩(본문 단서 기준, 판단 불가는 그대로 표시) |
| 니즈 교차 | 세그먼트 내 #해시태그 교차 언급 막대 상위 5 |
| 핵심 특징 | 3개, 각각 "수치 → 해석" |
| 니즈 상세 | #해시태그 × 3~5행: 페르소나 내 %, 건수, 설명, **원문 인용 5~6개** |

### 7.2 페르소나 카드: 뒷면 (FoD + 근거)
근거 정보는 뒷면에 둔다. PPS 연구에서 투명성을 높이면 신뢰성이 떨어지는 상충이 보고됐기 때문이다.

| 영역 | 내용 |
|---|---|
| FoD 저니 | 단계별 장벽 히트맵(n, CI, 가설 표시) |
| 태도·지불 | 태도 구성, 지불 의사 신호, 대체 행동, 결제자 ≠ 사용자 비율 |
| 생애 전환점 | 이 페르소나로 들어오는·나가는 전환 |
| 인사이트 필드 | 반복 패턴 · 기존 방식이 실패하는 이유 · 해결 방향 · 기대 가치 (repo `persona_messaging`) |
| 근거 등급 | strong / grounded / weak, 출처 구성, 안정성 수치 |
| 경계 | 이 카드로 말할 수 있는 것 / 없는 것, 데이터로 답할 수 없는 질문 |

### 7.3 기회-해법 트리 + FoD 아이템 카드

```
결과 (예: FoD 첫 구매 전환 ↑, 유료 전환 후 유지 ↑)
 └ 기회 = #해시태그 니즈·저니 장벽 (텍스트 신호 + 설문 ODI, 근거 수·CI)
    └ 해법 = FoD 아이템 (기존 개선 / 신규), 접점(앱·IVI), 과금 형태(월·평생·이용권·체험)
       └ 실험 = 체험권 A/B, 가격 테스트(설문 VW·GG), 현대차와 협의할 지표
```

- 기회 하나에 해법이 하나만 떠오르면 해법을 기회로 잘못 쓴 것이다. 기회를 다시 쓴다.
- 아이템 카드 형식(롯데마트 p14): 제목 + 연결 #해시태그 + 개념 1줄 + 구체안 3개(순간·접점·과금) + 시안.
- 킥오프 기준을 함께 적용한다: 편의 / HW 잠금처럼 보이지 않게 / 사용자의 순간에서 출발.

## Step 8. 설문 확정 ⏳

**대상:** 현대·기아·제네시스 FoD 탑재 가능 차종 보유자 + 1년 내 구매 예정자. 할당은 생애단계 × EV × 브랜드. **n ≈ 1,500**(세그먼트당 약 200 이상).

| 모듈 | 내용 | 표본 기준 |
|---|---|---|
| 8.1 세분화 | 상황형 문항 20~25개 → 설문 LCA → 텍스트 세그먼트와 ARI. 판별분석으로 골든 질문 8~12개, **실제 응답자로만 학습**, 홀드아웃 20~30% 정확도와 우연 기준선 보고 | 변수 하나당 70명 이상 |
| 8.2 ODI | 결과 문장(3.4) 20~30개의 중요도·만족도 → 세그먼트별 기회 점수. 텍스트 신호 지수와 순위 상관 | 세그먼트당 100명 이상 |
| 8.3 Kano | FoD 후보 12~20개, 기능형/역기능형 쌍 문항 | 보고 단위당 200명 이상 |
| 8.4 MaxDiff | 아이템 20~30개 상대 선호 | 총 300명 이상, 하위집단당 200명 이상 |
| 8.5 가격 | 상위 3~5개 아이템: 신규는 Van Westendorp, 기존은 Gabor-Granger. 과금 형태 비교 | 세그먼트당 100명 이상 |
| 8.6 태도·맥락 | "돈벌이" 인식, 체험 의향, 결제자/사용자, 대체재 보유, 저니 장벽 확인 | — |
| 8.7 사후 가중 | 설문 생애단계 × EV × 브랜드 분포로 텍스트 비중을 보정해 전/후 표기 | — |

- LLM 응답은 문항 사전 점검(이해도·변별력)에만 쓴다. 학습 데이터로는 쓰지 않는다.
- Kano와 MaxDiff는 응답자를 절반씩 나눠 배정한다. 가격 결정에는 8.4 + 8.5 조합을 우선한다.
- 현대차 데이터 요청(롯데마트의 CRM 결합에 해당): 상품별 판매·연령·채널·체험 전환율.
